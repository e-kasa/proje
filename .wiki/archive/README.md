# Archive

Bu klasör eskimiş veya superseded sayfaların taşıma yeri. Aktif silme yerine arşivleme tercih edilir — git history zaten silme kayıtlarını tutar ama wiki içinde geçmiş sayfaları aramak için bu klasör kullanışlıdır.

## Konvansiyon

- Dosya adına `-archived-YYYY-MM-DD` suffix eklenebilir
- Frontmatter'da `status: archived` + `archived-date: YYYY-MM-DD` + `superseded-by: <yeni-sayfa>`
- İçerik dokunulmaz (history korunur)
