# i18n

Tüm UI metinleri [[entities/security]] `data.sql` içindeki `message_definitions` tablosunda. `GET /security/i18n/all?lang=TR` → anahtar:metin map.

- **Flutter**: `i18nOf(ref)` → `t('key')`
- **React**: `menuService.getTranslations()`
- **Anahtar format**: `prefix.snake_case` (örn. `accounts.collect_payment`)
- **ID format**: `bnd-XX000-0000-0000-NNNNNNNNNNNN`
- **Modül prefix'leri**: bt, wz, pd, st, sl, pu, cu, su, rp, fn, se, au, cm, db
