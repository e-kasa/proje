Hangi özellikler var, hangileri eksik

Mevcut Şu An Var Olan Özellikler

  • ✓ Responsive 2-panel desktop layout (70/30)
  • ✓ Mobil layout + FAB ile sepet erişimi
  • ✓ Ürün arama (isim, SKU, barkod) + API entegrasyonu
  • ✓ Kategori filtreleme (horizontal chips)
  • ✓ Sepete ekleme, miktar değiştirme, silme
  • ✓ Yüzdelik indirim uygulama
  • ✓ Müşteri seçimi (bottom sheet)
  • ✓ 4 ödeme yöntemi (Nakit, Kart, Havale, Karma)
  • ✓ Para üstü hesaplama
  • ✓ Hızlı tutar butonları (nakit)
  • ✓ Satış API'ye gönderme
  • ✓ Loading/error state yönetimi
  • ⚠ Barkod girişi (sadece manual input)
  • ⚠ Ürün görselleri yok (placeholder ikon)

İdeal Olması Gereken Özellikler

  • ✗ Varyant seçimi — Birden fazla varyantı olan ürünlerde seçim yapabilme
  • ✗ Stok kontrolü — Sepete eklerken stok aşımı engelleme
  • ✗ Sabit tutar indirimi — Yüzde yerine ₺ bazında indirim
  • ✗ Fiş/Fatura yazdırma — Satış sonrası yazdırma seçeneği
  • ✗ Son satışlar — POS ekranında son satış geçmişi görüntüleme
  • ✗ Bekleyen sipariş (Park) — Satışı bekletip başka müşteriye geçme
  • ✗ Klavye kısayolları — F1: Ödeme, F2: Müşteri, F5: Yenile
  • ✗ Ürün görselleri — Gerçek ürün fotoğrafları
  • ✗ Kasa açılış/kapanış — Vardiya/kasa yönetimi
  • ✗ Offline modu — İnternet kesintisinde satış yapabilme
  • ✗ Müşteri oluşturma — POS'tan yeni müşteri ekleyebilme
  • ✗ Ondalık miktar desteği — Kilogram bazlı ürünler için
🚀 Önerilen İyileştirmeler
Öncelik sırasına göre yapılması gerekenler
🔴

1. Derleme Hatalarını Düzelt

Şu an POS ekranında ~15+ derleme hatası var. Önce bunların düzeltilmesi gerekiyor (pos_screen, pos_sales_screen, widget dosyaları).

🎯

2. Varyant Seçimi Ekle

Ürün kartına tıklayınca varyant varsa seçim dialog'u göster. Renk, boyut gibi seçenekler.

📊

3. Stok Kontrolü Güçlendir

Sepete eklerken ve miktar artırırken stok aşımını engelle. Kullanıcıya uyarı göster.

🧾

4. Fiş/Fatura Yazdırma

Satış tamamlandıktan sonra fiş yazdırma seçeneği. Termal yazıcı veya PDF desteği.

⏸️

5. Bekleyen Sipariş (Park)

Mevcut sepeti kaydedip yeni müşteriye geçme. Birden fazla açık sipariş yönetimi.

⌨️

6. Klavye Kısayolları

F1: Ödeme, F2: Müşteri, F5: Yenile, Escape: İptal, Enter: Sepete ekle, Barkod: auto-focus.
